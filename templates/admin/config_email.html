Guide de configuration — Gmail (recommandé)

  1. Connectez-vous à votre compte Google sur myaccount.google.com
  2. Allez dans Sécurité → activez la Validation en 2 étapes si ce n'est pas fait
  3. Dans Sécurité → Mots de passe des applications, créez un mot de passe pour "MonitorPro"
  4. Copiez le mot de passe généré (16 caractères) et collez-le dans le champ "Mot de passe d'application" ci-dessus
  5. Renseignez votre adresse Gmail dans "Email / Nom d'utilisateur"
  6. Serveur : smtp.gmail.com, Port : 587, TLS : activé
  7. Cliquez Sauvegarder & Envoyer un email de test pour vérifier
Note : Si SMTP est désactivé, les emails sont quand même simulés et consultables dans Responsable → Alertes → Historique Emails. L'activation SMTP permet de recevoir les alertes sur votre vraie boite mail.
